# Business Balance — برنامج محاسبة المسلخ والمطاعم

نظام محاسبي بالقيد المزدوج لثلاث شركات منفصلة (شركة الذبائح، مطعم دلي ١، مطعم دلي ٢)، مبني على
**Laravel 12 + Filament 3 + MySQL**، بواجهة عربية (RTL) وإنجليزية، وبأسلوب عمل قريب من أنظمة ERP
المعروفة: شريط حالة لكل مستند (مسودة ← مرحّل ← ملغى/معكوس)، أزرار ذكية تربط السند بقيده، سجل نشاط
لكل مستند، وقوائم بفلاتر وتجميع.

المرجع الملزم: وثيقة المتطلبات + ملف شجرة الحسابات + نموذج إقرار VAT 201 (في `database/data`).

## ما تم في هذا الإصدار (المرحلة الأولى + أساس الضريبة)

| المتطلب | أين |
|---|---|
| شركات متعددة، لكل شركة رقم ضريبي ودفاتر وإقرار مستقل | `Company` (Filament tenancy) |
| الفروع مع الإمارة (افتراضياً أبوظبي) | الإعدادات ← الفروع |
| السنة المالية من أي تاريخ + ١٢ فترة مفتوحة/مقفلة، إعادة الفتح بسبب مسجّل | الإعدادات ← السنوات والفترات |
| دليل حسابات ٤ مستويات، القيود على المستوى الأخير فقط، لا حذف لحساب عليه حركات | المحاسبة ← دليل الحسابات |
| استيراد الشجرة من Excel (نفس تنسيق الملف المرسل) | زر «استيراد من Excel» |
| حسابات النشاط المقترحة (مواشي، لحوم، مبيعات المطعم، منصات التوصيل، ضريبة الشركات، الحسابات الجارية بين الشركات) | `app/Services/Accounting/ActivityAccounts.php` |
| قيود يومية يدوية: مسودة ← ترحيل ← عكس | المحاسبة ← القيود اليومية |
| سندات القبض والصرف مع الكود الضريبي، تولّد القيد تلقائياً حسب جدول القسم ٣ | المحاسبة ← سندات القبض والصرف |
| ترقيم متسلسل بدون فجوات لكل نوع ولكل سنة (JV/RV/PV/REV-2026-00001) | `SequenceService` |
| التوازن، منع التعديل بعد الترحيل، القيد التلقائي لا يُعدّل يدوياً، منع الصندوق السالب | `PostingService` |
| الأدوار الخمسة القابلة للتعديل، التقييد بالفرع، حد اعتماد سندات الصرف (الترحيل حسب الصلاحيات فقط) | الإعدادات ← الأدوار / المستخدمون / إعدادات الشركة |
| سجل تدقيق لا يُحذف (محمي أيضاً بـ Trigger في MySQL) | الإعدادات ← سجل التدقيق + أسفل كل مستند |
| إقفال السنة بقيد تلقائي إلى الأرباح المبقاة وفتح السنة الجديدة | زر «إقفال السنة» |
| الأكواد الضريبية: 5%، صفر، معفاة، خارج النطاق، احتساب عكسي | الإعدادات ← الأكواد الضريبية |
| التقارير: ميزان المراجعة (بالأرصدة/بالمجاميع لأي مستوى)، كشف حساب، دفتر اليومية، قائمة الدخل مع مقارنة، الميزانية مع مقارنة، إقرار VAT 201 | قائمة التقارير، مع تصدير Excel وطباعة PDF والنزول إلى القيد |
| تصدير الإقرار على نموذج Excel نفسه الذي أرسلتموه | التقارير ← إقرار ضريبة القيمة المضافة ← تصدير |
| نسخ احتياطي يومي تلقائي واسترجاع | `php artisan backup:database` / `backup:restore` |

المبالغ تُخزّن `DECIMAL(18,2)` وتُحسب كأعداد صحيحة بالفلس (`App\Support\Money`)، ولا تُستخدم أرقام عائمة.

## المرحلة الثانية: المبيعات والمشتريات

| البند | التنفيذ |
|---|---|
| العملاء والموردون | قائمتان مستقلتان (المبيعات / المشتريات)، رقم ضريبي، مدة سداد، حد ائتمان (تنبيه أو منع)، طرف ذو علاقة |
| دفتر مساعد | كل عميل/مورد دفتر مساعد على الحساب الإجمالي (1131 / 2111) كما في ملاحظات الشجرة: سطر القيد يحمل `party_id` |
| الفواتير | بيع وشراء، آجل أو نقدي، رمز ضريبة لكل بند، ترقيم INV/CN/BILL/DN لكل سنة دون فجوات |
| القيد الآلي | يتولد عند التأكيد حسب §3 ولا يُعدّل يدوياً؛ الاحتساب العكسي يسجل ضريبة المدخلات والمخرجات معاً (المربعان 3 و10) |
| المرتجعات | إشعار دائن / مدين من الفاتورة الأصلية، يخصم تلقائياً من رصيدها |
| الدفعات | "تسجيل دفعة" من الفاتورة، أو تخصيص سند قبض/صرف على عدة فواتير، والباقي دفعة مقدمة |
| منع التكرار | لا يُقبل رقم فاتورة المورد نفسه مرتين لنفس المورد |
| التقارير | كشف حساب عميل/مورد، أعمار الديون (غير مستحق، 1-7، 8-15، 16-30، 31-60، 61-90، +90) |
| الفاتورة الضريبية | طباعة بالحقول الإلزامية (الرقم الضريبي للبائع والمشتري، الرقم، التاريخ، الصافي والضريبة والإجمالي بالدرهم) |
| الفوترة الإلكترونية | تصدير UBL 2.1 (PINT AE) وJSON، وتتبع الحالة (مرسلة/مقبولة/مرفوضة + السبب). الفاتورة المرسلة لا تُلغى بل تُصحَّح بإشعار دائن |

## المرحلة الثالثة: البنوك والمخزون والأصول

| البند | التنفيذ |
|---|---|
| التحويلات | تحويل بين الصناديق والبنوك برقم TRF، ترحيل وإلغاء بقيد عكسي |
| الشيكات | سجل شيكات مستلمة وصادرة برقم وتاريخ استحقاق وبنك. الشيك المستلم يمر عبر 1119 (بالصندوق ← مودع ← مرتجع)، والصادر عبر 2126 (صادر ← مصروف ← مرتجع). المرتجع يعيد فتح الفاتورة |
| التسوية البنكية | استيراد كشف Excel/CSV (عناوين عربية أو إنجليزية)، مطابقة تلقائية بالمبلغ والتاريخ والمرجع، مطابقة يدوية، مذكرة تسوية تشرح الفرق، واعتماد عند فرق صفر |
| بطاقة الصنف | رمز، باركود، وحدة أساسية ووحدات إضافية بمعامل تحويل وسعر، سعر بيع، ضريبة، حسابات مبيعات/مخزون/تكلفة |
| المخزون | جرد مستمر بالمتوسط المرجح، مستودع لكل فرع، تحويل بين المستودعات، منع البيع بالسالب (قابل للتعديل من بيانات الشركة)، فاتورة البيع ترحّل تكلفة المبيعات آلياً |
| مستندات المخزون | مخزون افتتاحي، صرف، تحويل، جرد فعلي مع قيد الفروقات، تكاليف شحن وجمارك توزع على فواتير الشراء بالقيمة أو الكمية |
| الأصول الثابتة | بطاقة أصل، إهلاك قسط ثابت شهري لكل الأصول بزر واحد (قيد DEP واحد)، بيع أو استبعاد مع ربح/خسارة آلي |
| مراكز التكلفة | شجرة مستقلة، مركز على سطر القيد والسند والفاتورة، تقرير ربحية، وفلتر مركز التكلفة على ميزان المراجعة وقائمة الدخل وكشف الحساب |
| تعدد العملات | أسعار صرف بالتاريخ، الفاتورة تحفظ المبلغ الأجنبي والسعر والمعادل بالدرهم، شطب فروق العملة |
| التقارير | التدفقات النقدية (غير مباشرة، مع تحقق)، حركة الصناديق والبنوك، أرصدة المخزون، بطاقة صنف، الأصناف الراكدة، سجل الأصول، ربحية مراكز التكلفة |
| استيراد Excel | قوالب قابلة للتنزيل: العملاء، الموردون، الأصناف، الأصول، الفواتير المفتوحة الافتتاحية، المخزون الافتتاحي (دليل الحسابات من شاشته) |

حدود معروفة: الحركات بتاريخ سابق تُقيَّم بمتوسط التكلفة وقت الترحيل، وطريقة FIFO غير مفعلة (المتوسط المرجح فقط)،
والربط الفعلي مع مزوّد الفوترة الإلكترونية (ASP) ينتظر التعاقد.

## التشغيل محلياً

```bash
composer install
cp .env.example .env && php artisan key:generate
# اضبط DB_* في .env
php artisan migrate --seed            # ٣ شركات + الأدوار + مستخدم لكل دور
SEED_DEMO=true php artisan db:seed --class=DemoSeeder   # بيانات تجريبية (اختياري)
php artisan storage:link
php artisan serve                       # http://localhost:8000/admin
```

مستخدمو البداية (كلمة المرور من `SEED_PASSWORD`، الافتراضي `password`، **غيّروها فوراً**):

| البريد | الدور |
|---|---|
| admin@example.com | مدير النظام |
| chief@example.com | رئيس الحسابات |
| accountant@example.com | محاسب |
| entry@example.com | مدخل بيانات |
| management@example.com | الإدارة |

المذكورة حرفياً، توازن الميزان والميزانية، خانات الإقرار، إقفال السنة، والنسخ الاحتياطي.
